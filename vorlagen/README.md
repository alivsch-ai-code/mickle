# Vorlagen

Fertige Prompts zum Kopieren, thematisch sortiert. Regeln für neue
Dateien: [`CONTRIBUTING.md`](../CONTRIBUTING.md#prompts-und-workflows) —
kurze Beschreibung des Zwecks, und mit welchem Werkzeug/Modell der Prompt
getestet wurde (oder ausdrücklich als ungetestete Übungsvorlage
gekennzeichnet, statt einen Test zu behaupten, der nicht stattgefunden
hat).

wird — mit Verweis aus dem Anwendungsfall auf die Datei hier.
